# DEPLOYMENT INSTRUCTIONS
# Simple 3-step deployment

## STEP 1: Extract this folder to your Desktop
Replace your existing ReportLab folder with this one.
Location: C:\Users\kim_j\Desktop\ReportLab

## STEP 2: Push to GitHub

Open VS Code in the ReportLab folder, then run:

```
git add .
git commit -m "Restructure for multi-state support: states/new_york architecture"
git push
```

## STEP 3: Update Digital Ocean

1. Go to: https://cloud.digitalocean.com/apps
2. Click "Goldfish" app
3. Settings → App-Level Settings
4. Find "Source" section → Click "Edit"
5. Source Directory: (DELETE "New York/pdf-service" - leave BLANK)
6. Click Save
7. App auto-deploys

## STEP 4: Test

After deployment completes (~3-5 min):

```
curl https://your-goldfish-url.ondigitalocean.app/health
```

Should return:
```json
{
  "status": "healthy",
  "service": "divorcegpt-pdf-multistate",
  "states": ["ny"]
}
```
